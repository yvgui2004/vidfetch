# VidFetch — 批量视频下载器

粘贴多个视频网址，自动获取标题和格式，按预设画质**并行下载**视频+音频并合并为 MP4。

基于 [yt-dlp](https://github.com/yt-dlp/yt-dlp) + [CustomTkinter](https://github.com/TomSchimansky/CustomTkinter) 构建。

## 功能

- **批量输入** — 支持换行、空格、紧挨着粘贴，自动智能切分网址
- **自动获取** — 添加网址到队列后后台自动拉取视频标题和所有可用格式
- **格式预览** — 点击队列任意项，下方自动展示该视频的全部格式（分辨率、编码、码率、大小）
- **画质预设** — 最高画质+音质 / 1080p / 720p / 仅音频，一键切换
- **并行下载** — 可选 1-6 个同时下载，`Semaphore` 控制并发
- **实时进度** — 每个任务独立显示速度和 ETA，总进度条汇总
- **Cookies 支持** — 粘贴浏览器 Cookies 下载需要登录的内容
- **深色主题** — 适配 Windows 11 标题栏 Mica 效果

## 安装

### 依赖

```bash
pip install customtkinter yt-dlp pywinstyles
```

### 额外依赖

- **FFmpeg** — 合并视频+音频为 MP4 必需。下载后加入系统 PATH，或放在 `vidfetch.py` 同目录下。
  - 下载: https://ffmpeg.org/download.html
  - Windows 一键安装: `winget install ffmpeg`

### 运行

```bash
cd VidFetch
python vidfetch.py
```

## 使用

1. **粘贴网址** — 把多个视频网址粘贴到左侧文本框（换行、空格、紧挨着都行）
2. **选择预设** — 选画质偏好（默认"最高画质+音质"即可）
3. **添加到队列** — 点"➕ 添加到队列"，后台自动获取标题和格式
4. **开始下载** — 点"▶ 开始下载"，选保存目录，开始并行下载
5. **查看进度** — 队列表格实时更新，总进度条显示整体进度

> **提示**: 首次使用建议先放 1 个网址测试，确认网络和 FFmpeg 正常。

## 画质预设说明

| 预设 | yt-dlp 格式串 | 说明 |
|------|-------------|------|
| 🎯 最高画质+音质 | `bestvideo+bestaudio/best` | 最高码率视频 + 最高码率音频，合并 |
| 📺 1080p + 最佳音质 | `bestvideo[height<=1080]+bestaudio/best[height<=1080]` | 视频封顶 1080p |
| 📺 720p + 最佳音质 | `bestvideo[height<=720]+bestaudio/best[height<=720]` | 视频封顶 720p |
| 🎵 仅最高音频 | `bestaudio/best` | 只要音频，不下载视频 |

## 并发控制

侧边栏可选择 1-6 个同时下载。建议：
- **1-2**: 稳定，适合限速严格的网站
- **3**: 默认，快且稳
- **4-6**: 网速好、视频不大时更快，但可能触发限流

## 技术栈

- **yt-dlp** — 视频格式解析和下载引擎
- **CustomTkinter** — 现代桌面 UI 框架
- **pywinstyles** — Windows 11 标题栏 Mica 效果
- **threading + Semaphore** — 并发下载控制
- **ttk.Treeview** — 格式表格和队列表格
